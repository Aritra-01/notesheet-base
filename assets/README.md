# 📸 README Assets

This directory should contain:

| File | Description |
|------|-------------|
| `banner.png` | Light mode banner image (1920x600px recommended) |
| `banner-dark.png` | Dark mode banner image (1920x600px recommended) |
| `before-slide.png` | Screenshot of a dark lecture slide (before transformation) |
| `after-sheet.png` | Screenshot of print-ready white sheet (after transformation) |
| `demo.gif` | Animated GIF showing the full workflow (optional) |

## Generating Banner Images

You can use the running app to generate screenshots:
1. Run `pnpm dev` and open http://localhost:3000
2. Upload a dark PDF
3. Configure your preferred layout and filters
4. Take screenshots and save to this directory

## Recommended Tools for GIF Creation

- **LICEcap** (Windows/Mac) — simple animated screen capture
- **ScreenToGif** (Windows) — feature-rich GIF recorder
- **ezgif.com** — online GIF maker and optimizer
