# 🤝 Contributing to NoteSheet

Thank you for your interest in contributing!

## How to Contribute

### 🐛 Bug Reports
Please open an issue with:
- Clear description of the bug
- Steps to reproduce
- Expected vs actual behavior
- Browser and OS information

### 💡 Feature Requests
We welcome new ideas! Please open an issue with:
- Clear description of the feature
- Use case / why it's needed
- Any mockups or examples if applicable

### 🔧 Pull Requests

1. **Fork** the repository
2. **Clone** your fork: `git clone https://github.com/YOUR_USERNAME/notesheet-base.git`
3. **Create a branch**: `git checkout -b feature/amazing-feature`
4. **Install dependencies**: `pnpm install`
5. **Make your changes** and add tests if applicable
6. **Run tests**: `pnpm test`
7. **Build**: `pnpm build`
8. **Commit**: `git commit -m 'Add amazing feature'`
9. **Push**: `git push origin feature/amazing-feature`
10. **Open a Pull Request**

### 📋 Coding Standards

- TypeScript strict mode
- Run `pnpm test` and `pnpm build` before submitting PRs
- Follow existing code style and structure
- Document new features in code comments

### 🧪 Running Tests

```bash
pnpm test        # Run unit tests
pnpm test:watch  # Run tests in watch mode
```

### 🏗️ Development Workflow

```bash
pnpm dev         # Start dev server at http://localhost:3000
pnpm build       # Production build
pnpm preview     # Preview production build
```

## 📖 Documentation

Please update documentation (README.md, code comments) when adding or changing features.

## 🎯 Areas for Contribution
